# Public Showcase Maintenance Runbook

1. Keep client identity and commercial details out of the repository.
2. Do not copy PBIX, DOCX, raw datasets, private screenshots or conversations from the engineering repository.
3. Add only evidence-backed capabilities and aggregate outcomes.
4. Keep descriptive association separate from causal interpretation.
5. Preserve sample-size context when publishing segment rates.
6. Run the disclosure-boundary workflow before treating a change as publishable.
7. If disclosure status becomes uncertain, keep the material private until reviewed.
