# Engineering Lessons Learned

1. More variables do not automatically create a better dashboard.
2. Correlated lifecycle variables need interpretation, not repetition.
3. Percentages need sample-size context.
4. Power Query and DAX should have distinct responsibilities.
5. Small missing-value volumes should not be silently manufactured away.
6. Presentation language matters when the analysis is descriptive.
7. Replication documentation is part of the product.
