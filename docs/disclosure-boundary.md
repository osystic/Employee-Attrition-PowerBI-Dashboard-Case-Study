# Disclosure Boundary

## Included publicly
- sanitized problem framing
- Power BI architecture
- Power Query and DAX methodology
- aggregate validation metrics
- analytical interpretation
- engineering lessons
- public-safe diagrams

## Excluded
- client identity
- raw employee records
- raw CSV/XLSX files
- PBIX delivery file
- DOCX delivery file
- private screenshots or conversations
- commercial or payment information
- credentials, local paths or private infrastructure
- confidential repository history

If disclosure status becomes uncertain, the material stays private until reviewed.
